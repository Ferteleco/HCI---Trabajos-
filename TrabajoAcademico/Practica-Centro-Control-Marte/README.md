# Centro de control de Marte

Práctica individual (30 minutos) de HCI: página web HTML y CSS para supervisar una misión a Marte.

## Contenido

- Cabecera con título.
- Imagen de la misión (en esta versión, un bloque CSS de marcador; sustituir por una imagen propia).
- Cuatro indicadores: oxígeno, energía, temperatura y progreso.

## Técnicas utilizadas

- **CSS Grid** para la disposición de la imagen y de los indicadores.
- **Unidades relativas** (`rem`, `%`, `vw`, `clamp()`) en lugar de píxeles fijos.
- **Media queries** para pasar de una columna a dos, y de dos a una disposición de escritorio.

## Validación

Comprobar en el navegador (DevTools, modo responsive) a 360 px y a 1200 px de ancho que no aparece scroll horizontal.

## Cómo verla

Abrir `index.html` en el navegador, o usar la URL de GitHub Pages del repositorio.
